## About

This site brings together who I am, what I've built and where I'm headed. It is the best place to see how I approach problems.

My path into data science started in sociology, where I learned to ask why people and organizations behave the way they do. Now I answer those questions with evidence. My current research looks at how growing reliance on AI is changing the way businesses make decisions, especially in consulting, using industry data on AI adoption and consulting spending over time.

I'm completing my M.S. in Applied Data Science & Analytics at Howard University (expected 2026), and I'm drawn to work where data can drive evidence-based decisions and more equitable outcomes.

## Built With

- **GitHub Pages** for free hosting directly from this repository
- **HTML & CSS** written by hand, with no frameworks
- **Jekyll** (GitHub Pages' built-in site builder) for page URLs and site settings
- **Responsive design** using CSS Grid, Flexbox and media queries, so both pages work on desktop and mobile

---

## Updating the Site

1. Edit `index.html` or `resume.html`.
2. Commit the changes to the `main` branch.
3. GitHub Pages rebuilds automatically. Changes go live in about 1–2 minutes (check the **Actions** tab for a green check).
